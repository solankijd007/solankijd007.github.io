# Spider Portfolio (Next.js 16.2.2)

This project has been migrated from Vite to Next.js App Router.

## Stack

- Next.js `16.2.2`
- React `19.2.4`
- Tailwind CSS `4`
- GSAP + Three.js

## Scripts

- `npm run dev` → start development server
- `npm run build` → production build
- `npm run start` → run built app
- `npm run lint` → run ESLint

## Project Entry

- App layout: `src/app/layout.jsx`
- Home page: `src/app/page.jsx`
- Global styles: `src/app/globals.css`

## Notes

- Existing section components are used from `src/components`.
- Components with hooks are configured as Client Components via `'use client'`.
